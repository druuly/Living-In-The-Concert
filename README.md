# Abstract
This capstone project addressed the issue of concert-goers failing to review recorded video by developing a wearable, Arduino ESP32-based device that monitors physiological arousal via heart rate and Galvanic Skin Response (GSR). The prototype successfully met requirements for weight (0.26 lbs), cost ($75.02), and app size (781 KB), though Android compatibility and 30-second clipping constraints were not met, resulting in a system that logs timestamps of peak engagement.
